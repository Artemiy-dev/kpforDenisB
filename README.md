# КП-Штамп — деплой на Vercel

Один файл `index.html`, без сборки и без сервера — всё выполняется в браузере пользователя.

## Что внутри

- Открывает загруженный PDF/фото КП и рисует поверх него дату, номер и (по желанию) цену — сам исходный файл не меняется, кроме этих штампов.
- Дата, номер, цена без НДС/с НДС определяются в PDF автоматически (по тексту "Дата", "Исх. №", "без НДС", "с НДС"); если не нашлось — есть ручная калибровка кликом по макету.
- Счётчик номеров (ПРЕФИКС-ММ-№№№) и история сохранённых КП хранятся в `localStorage` браузера — то есть каждый компьютер/браузер ведёт свою историю. Если нужна общая история на несколько устройств, потребуется своя база данных (не входит в этот файл).
- Скачивание готового PDF — через открытие в новой вкладке (браузер сам предложит сохранить).

## Деплой на Vercel

Самый простой способ — через сайт, без установки чего-либо:

1. Зайдите на vercel.com и войдите (можно через GitHub/Google).
2. New Project → Add New... → выберите "Deploy" без Git-репозитория, либо перетащите папку с `index.html` в область загрузки на странице импорта проекта.
3. Framework Preset оставьте "Other" — сборка не нужна, файл статический.
4. Deploy. Через ~30 секунд получите ссылку вида `https://ваш-проект.vercel.app`.

Через терминал (если удобнее):

```bash
npm i -g vercel
cd kp-stamp-vercel
vercel --prod
```

## Свой домен

В настройках проекта на Vercel → Domains можно подключить свой домен (например kp.gasstrade.kz), следуя подсказкам на экране (нужно будет добавить DNS-запись у регистратора домена).

## Важно

- Сайт публичный по ссылке — доступ к нему не защищён паролем. Если нужно ограничить доступ, это делается через настройки Vercel (Password Protection — платная функция) либо добавлением своей простой авторизации.
- Шрифт PT Sans/PT Serif подключается с Google Fonts, а библиотеки pdf.js / pdf-lib — с cdnjs.cloudflare.com и cdn.jsdelivr.net. Интернет на компьютере пользователя должен иметь доступ к этим адресам (для обычного пользователя из Казахстана проблем быть не должно).
